Electricity Consumption Management System

Technologies:
Python, Tkinter, MySQL, Pandas, NumPy, Matplotlib

Setup:
1. Run: python -m pip install -r requirements.txt
2. Run database_setup.sql in MySQL Workbench.
3. In database.py, replace YOUR_PASSWORD with your MySQL root password.
4. Run: python main.py

No Machine Learning or Streamlit is used.
